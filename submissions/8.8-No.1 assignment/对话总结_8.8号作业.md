## 七、关键知识点备忘（你边做边学的）

- **Git CMD vs Git Bash**：同一 git 程序，两种"驾驶台"。CMD 用 Windows 命令（dir/copy），Bash 用 Linux 命令（ls/cp）。教程默认 Git Bash，你已装好，开始菜单里找。
- **显示名 vs 登录名**：填网址/git 永远用登录名 `xiyun872`，别用显示名 `xiyun`。
- **VPN 原理**：VPN 不是网络，是叠加在 WiFi/流量之上的**加密隧道**；**开 VPN 时必须保持 WiFi/流量开启**，否则断网。
- **华为侧载**：无 Google Play，装 App 靠「设置→安全→安装未知来源应用」开权限后点 APK；遇"纯净模式"点继续安装。
